# 📰 NewsFeedApp

**NewsFeedApp** is a modern Android application built with Kotlin that provides users with the latest news in a clean and intuitive interface.  
The app is designed to help users quickly explore, filter, and read articles from multiple categories, offering a smooth reading experience with offline support.

---

## ✨ Features

- 🗞️ **Browse news** across multiple categories (Politics, Sports, Technology, etc.)  
- 🔍 **Search functionality** to quickly find specific articles  
- ⭐ **Featured news** highlighted at the top of each category  
- 💾 **Offline mode** – previously fetched articles are available even without internet  
- 🗂️ **Category chips** to easily switch between different topics  
- 📱 **Responsive & modern UI** following Material Design principles

## 🛠️ Built With

- **Kotlin** – Primary programming language  
- **Android Jetpack (ViewModel, LiveData, Room)** – Architecture components  
- **Retrofit** – Networking and API calls  
- **Coil** – Image loading  
- **Material Components** – Modern UI design system  
- **RecyclerView** – Efficient news listing  
- **Room Database** – Offline storage and caching

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/KerimSikalo/NewsFeedApp.git
2. Open the project in Android Studio

3. Click Sync Project with Gradle Files to install dependencies

4. Run the app on an emulator or a physical Android device
